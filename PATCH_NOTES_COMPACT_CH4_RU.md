# AELABS WEB v2.1 — компактный интерфейс и зелёная подача метана

- Основой служит сборка `AELABS_WEB_v2.1_GIT_WEB_CH4_FLOW.zip`.
- В карточке **«Подача CH₄»** молекула заменена на три анимированных потока — ровно той же SVG-геометрии и анимации, что в карточке «Подача воздуха», но зелёного цвета.
- Скорость анимации потоков реагирует на числовой расход CH₄ (л/мин) так же, как анимация воздуха.
- Удалена отдельная подпись под карточкой (включая «Нет связи с GIT WEB»); общий статус подключения, аварии и диагностика связи остались.
- Весь веб-интерфейс стал компактнее: уменьшены гигантский заголовок, отступы, высота карточек и иллюстраций, размеры типографики и графиков. Учтены мобильные размеры.
- Поле показаний **не менялось**: `measurements.ch4_flow_online_ae_l_min` через `/api/latest`, то есть через GIT WEB (`data/live/latest.json`). GIT LOG, обработка истории, сигналы и другие каналы не менялись.
- Если метан не приходит из WEB, вместо выдуманного показания отображается `—`, но лишней подписи под карточкой нет.

## Развёртывание

Заменить файлы в репозитории сайта AELABS WEB содержимым архива и выполнить redeploy. Настройки `GITHUB_OWNER`, `GITHUB_REPO`, `GITHUB_TOKEN` оставлять привязанными к **GIT WEB**; лог-репозиторий не изменять.
