# История и непрерывный тренд AELABS WEB

- Для GitHub GIT LOG CSV читается вся доступная история, а не только последние 500 записей.
- Сервер формирует компактный набор до 2400 реальных строк на всём временном диапазоне файла. При сокращении набора сохраняются начало, конец и локальные минимумы/максимумы каждого сигнала. Таблица последних измерений отдельно использует до 100 исходных строк.
- Тренд не показывает круговые маркеры измерений и не разрывает линию из-за временной паузы, включая выход с веб-страницы и повторный вход позже.
- По оси X используется исходное время `source_time_raw`/`event_time_utc`. Время получения файла и часы браузера не используются для создания новых измерений.
- При пропущенном значении линия соединяет соседние реальные значения этого параметра; отсутствующее измерение не заменяется точкой или выдуманным значением.
- Сглаживание применяется только между реальными измерениями. Анимация перерисовки удалена, чтобы график не выглядел как сбрасывающийся при автообновлении.
- История из GitHub CSV остаётся источником истины при каждом открытии страницы; кэш браузера используется только как резервный локальный вариант.
- LIVE-карточки обновляются раз в 5 секунд, CSV-история — раз в 15 секунд с серверным кэшированием.

## Проверки

- Тесты CSV проверяют сохранение более 500 записей и масштабирование истории с сохранением начала/конца и последних исходных записей.
- Тесты нормализации и проверки исходного времени проходят.
- JavaScript в `static/index.html` проверен на синтаксические ошибки.
