# Выбор тем интерфейса AELABS WEB

В нижней панели доступны две темы:

- **Классика** — исходный тёмный технический интерфейс; используется по умолчанию.
- **Frutiger Aero** — светлая стеклянная тема в эстетике Windows Vista.

Выбор сохраняется в localStorage браузера. Источники данных, API, обновление показателей, тренды и история измерений не изменены.
