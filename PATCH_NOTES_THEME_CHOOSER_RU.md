# Выбор тем интерфейса AELABS WEB

Добавлена закреплённая снизу панель выбора темы с тремя вариантами:

- **Русская** — текущий ретро-футуристический дизайн с триколорами и декоративными блоками.
- **Классика** — исходная тёмная техническая тема мониторинга.
- **Frutiger Aero** — светлая стеклянная тема в эстетике Windows Vista: глянцевые градиенты, объёмные кнопки, бликовые поверхности и водно-голубые цвета.

Выбор темы сохраняется в localStorage этого браузера и восстанавливается при повторном открытии. Источники данных, обновление, API, графики, таблица истории и сценарии уведомлений не изменены. В не-русских темах скрываются декоративные российские блоки, чтобы они соответствовали выбранному оформлению.
