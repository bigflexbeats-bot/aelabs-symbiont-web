# Исправления AELABS WEB

- Опрос страницы и синхронизация с API выполняются раз в 5 секунд.
- Сервер кэширует `latest.json` на 4 секунды: посетители используют общий кэш и не создают отдельный GitHub-запрос на каждый браузерный опрос.
- Убран рекурсивный обход Git-дерева и чтение до 50 исторических файлов из GitHub. История в Git не записывается.
- Тренд собирает точки из текущих LIVE-снимков и сохраняет до 500 точек в локальном хранилище браузера. История переживает перезагрузку страницы на том же браузере.
- Запросы страницы не накладываются друг на друга при медленном ответе.

Важно: для общего тренда между разными устройствами нужен отдельный серверный накопитель; сейчас история намеренно локальна и не отправляется в GitHub.
