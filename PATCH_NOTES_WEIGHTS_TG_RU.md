# Индикация весов и ссылка Telegram

- Индикация весов как в настольном приложении: жёлтый порог и красный (критический) уровень. Пороги берутся из JSON (`weight_thresholds`, `weight_limits`, `desktop_status.weight_thresholds` или плоские поля `weight_N_yellow_kg` / `weight_N_red_kg`) либо из переменных Render `WEIGHT_YELLOW_KG`, `WEIGHT_RED_KG` (общие) или `WEIGHT_N_YELLOW_KG`, `WEIGHT_N_RED_KG` (по весам). Если ничего не задано — прежние значения 2 кг / 1 кг. Если настольное приложение публикует `active_alarms` с `alarm_state_authoritative=true`, состояние весов берётся из него.
- Что показывается: цветной бейдж на карточке («Жёлтый порог» / «Критический уровень»), пульсирующая рамка, цвет значения, цвет жидкости в ёмкости, пунктирные линии порогов на ёмкости и строка в списке тревог.
- Логотип внизу страницы ведёт на https://t.me/aeetherwave (новая вкладка).
