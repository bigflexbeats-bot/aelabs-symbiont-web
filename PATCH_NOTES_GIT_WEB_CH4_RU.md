# AELABS WEB v2.1 — подача CH₄ из GIT WEB

## Изменено

- Добавлена карточка «Подача CH₄» с показаниями РРГ-20 в л/мин.
- Источник строго `data/live/latest.json` из репозитория GIT WEB, настроенного через `GITHUB_OWNER`/`GITHUB_REPO` в `app.py` (API `GET /api/latest`).
- Ключ `observation.measurements.ch4_flow_online_ae_l_min` (или `measurements.ch4_flow_online_ae_l_min` в обычном формате). **Не путать** с `offgas_ch4_online_ae_pct`: второе поле — доля CH₄ в абгазе, %.
- Раздел «Подача газов»: существующая карточка воздуха / O₂ и новая карточка метана. Стили старой версии сохранены.
- Отдельный график подачи CH₄ из WEB-наблюдений с исходными метками времени. Линия прерывается при отсутствующих показаниях и разрывах >30 секунд. Никаких точек по времени опроса/получения файла не создаётся.
- График хранит до 500 уникальных WEB-наблюдений **локально в браузере**, отображает последние 120. Пока браузер не посещал сайт, старую историю из GIT WEB `latest.json` восстановить невозможно: этот файл содержит только последний снимок. Сохранённая браузерная история не является серверным журналом и не переносится между браузерами.
- Отсутствие канала показывает «—», ноль (0.000 л/мин) отображается как валидное показание; есть сообщения о недоступной связи и устаревании.

## Что не менялось

- **GIT LOG и его CSV / публикация не менялись.** Старые тренд, `api/history`, сбор данных, сигнализация и базовый дизайн остаются как были.
- Настольное приложение, прошивка и путь `data/live/latest.json` не менялись.
- Звуковые сигналы/весы/данные абгаза не менялись.

## Развёртывание

Обновить содержимое репозитория **сайта AELABS WEB**, используя файлы из архива, и выполнить redeploy на Render. Убедиться, что в настройках веб-сервиса `GITHUB_OWNER`, `GITHUB_REPO`, `GITHUB_BRANCH` и `GITHUB_TOKEN` по-прежнему указывают на репозиторий **GIT WEB** с `data/live/latest.json`. Не загружайте веб-приложение в репозиторий логов и не меняйте назначения каналов в AELABS.

Проверка: `/api/latest` должен содержать `measurements.ch4_flow_online_ae_l_min` (число или `null`). Если поле отсутствует/`null`, сайт честно покажет «—»; в этом случае нужно диагностировать передачу из настольного AELABS в GIT WEB, а не GIT LOG.
