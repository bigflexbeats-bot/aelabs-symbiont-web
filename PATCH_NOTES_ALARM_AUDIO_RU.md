# AELABS WEB v2.1 — восстановление звуковой сигнализации (21.11.2026)

Основа: `AELABS_WEB_v2.1_GIT_WEB_CH4_COMPACT_GREEN.zip`. Сохранены компактный интерфейс, зелёная анимация потока CH₄, карточки, CSV-тренды, GIT WEB/GIT LOG и существующие API.

## Исправления

- Вернул видимые элементы сигнализации: в оригинале `.alarm-strip-head` был скрыт `display:none`, поэтому «Включить звук ошибок» не отображалось.
- Теперь **кнопка «Включить звук» постоянно видна в верхней панели** даже при ошибке связи.
- Добавил панель: количество активных сообщений, состояние звука, громкость, «Проверить звук», «Квитировать».
- Критическая ошибка/обрыв источника (в том числе HTTP 502) запускает повторяющийся сигнал до квитирования, устранения ошибки или выключения звука.
- Желтая сигнализация выдаёт короткое предупреждение один раз на новое событие. При переходе жёлтой тревоги в красную звук снова включается, даже если жёлтая была квитирована.
- Квитирование выключает звук, но **не удаляет** сообщение об аварии. После устранения и повторного появления авария заново озвучивается; новая авария с другим идентификатором тоже озвучивается.
- Отключение и повторное включение звука работает в обе стороны. Громкость запоминается на конкретном устройстве.
- Звуковые файлы `static/alarm-critical.wav` и `static/alarm-warning.wav` сгенерированы в совместимом 16-bit PCM, не используют внешние сервисы и не требуют JavaScript-библиотек.
- Не менялись `app.py`, пути API, переменные GitHub, Render и серверная обработка данных.

## Как включить звук

1. Открыть сайт в браузере.
2. **Каждый раз после загрузки страницы** нажать «🔇 Включить звук» в верхней строке — браузер требует действие пользователя для аудио.
3. Проверить звук кнопкой «Проверить звук» (в отсутствие аварии воспроизводится краткий сигнал).
4. При активной красной тревоге повторяется аварийный звук. «Квитировать» временно заглушит текущие активные события до их исчезновения или появления новой тревоги.

**Важно**: Звуковая сигнализация браузера работает только при открытой странице, включенном звуке и работающем браузере/ОС. Фоновая вкладка, спящий ПК или ограничения автозапуска звука могут препятствовать оповещению. Это дополнительная система мониторинга, не замена независимой аварийной защите оборудования.

## Публикация

Загрузить **содержимое архива в корень публичного репозитория сайта**. Render должен использовать прежний `render.yaml` / `Procfile`; переменные окружения `GITHUB_TOKEN` и другие секреты не включаются в архив. При ошибке HTTP 502 отдельно проверить чтение данных из GitHub на Render, так как это серверная проблема и данный патч её не устраняет.
