# AELABS WEB — hotfix тренда

## Что исправлено
- Тренд добавляет локальную точку на каждом успешном опросе API, даже если publisher повторно использует тот же timestamp/observation_no.
- Для одного успешного опроса точка обновляется без дубля в пределах 4 секунд.
- Добавлены видимые точки для одиночных измерений и плоских участков, чтобы график не выглядел пустым при постоянных значениях.
- SVG-график строится с защитой от нулевого диапазона и отображает время начала/конца выбранного окна.
- Хранение тренда остаётся локальным в браузере (localStorage); GitHub history не используется.
- Период опроса остаётся 5 секунд.

## Развёртывание
Замените файлы веб-проекта содержимым этого пакета и выполните redeploy на хостинге. Затем откройте сайт с жёстким обновлением (Ctrl+F5). После первого успешного получения числовых значений точки появятся сразу; линия будет формироваться по мере накопления следующих опросов.

## Проверка
JavaScript синтаксис проверен через Node.js. Полный end-to-end тест требует доступного GitHub API и запущенного хостинга.
