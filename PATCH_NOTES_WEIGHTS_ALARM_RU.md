# Исправление весов и звуковой сигнализации

- Исправлена совместимость формата весов: веб принимает `weight_1_g` / `weight_2_g` / `weight_3_g` из AELABS MONITORING v38 и переводит граммы в килограммы для карточек и порогов.
- Сохранена поддержка прежних полей `weight_N_kg`.
- Добавлена кнопка «Включить звук ошибок»: браузер требует явного действия пользователя перед воспроизведением звука.
- При появлении нового активного сообщения уровня «ошибка», включая потерю связи/ошибку чтения данных, воспроизводится `static/signal.wav` один раз на переход в состояние ошибки. При устранении и повторном появлении ошибки сигнал срабатывает снова.
- Звуковая сигнализация работает, пока страница открыта; для неё нужно один раз нажать кнопку включения звука.
