# Карточка поддержки после закрытия медведя — локализация для России

- После закрытия панели с медведем появляется ненавязчивая карточка с поддерживающим сообщением.
- Основной контакт для России: телефон психологической помощи МЧС России +7 (495) 989-50-50. Официальный сайт МЧС указывает, что линия работает круглосуточно, анонимно и бесплатно; междугородняя связь оплачивается отдельно.
- Добавлена ссылка на интернет-службу экстренной психологической помощи МЧС России: https://psi.mchs.gov.ru/.
- Добавлена ссылка на список региональных телефонов доверия МЧС России.
- При непосредственной опасности для жизни указан единый номер экстренных служб 112.
- Карточку можно закрыть кнопкой × или клавишей Esc.
- Карточка появляется только после закрытия медведя; после собственного закрытия повторно не показывается в рамках текущей загрузки страницы.
- Изменения касаются только текста и ссылок интерфейса. Данные, API, CSV, GitHub и графики не изменялись.
