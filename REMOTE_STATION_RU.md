# Управление титростанцией через GIT WEB

Используются существующие репозиторий и ветка GIT WEB. Десктоп читает заявку
из `data/control/titration-buffer.json`, а результат публикует в том же
`data/live/latest.json` в поле `observation.titration_station.remote_result`.
GIT LOG и локальный CSV продолжают работать по своим настройкам.

На ПК остаётся существующая настройка GIT WEB. В Render существующей переменной
`GITHUB_TOKEN` требуется право Contents: Read and write для того же приватного
репозитория и ветки. Этот токен остаётся на сервере. Никаких новых переменных,
ключей подписи, входа в веб и подтверждения оператором не требуется.

В разделе «Станция титрования» на сайте выберите режим, порог pH, дозу или паузу и отправьте
одно новое значение. Десктоп применяет его автоматически.
Смена режима проходит через штатный контроллер AE AUTOLABS и проверку уставок.
Для включения полуавтомата или автомата нужны свежие данные INI. Пороги pH, дозы и паузы
меняются в ручном режиме. Для любой команды требуются остановленные насосы,
свежая телеметрия ESP32, снятый аварийный стоп и завершённая диагностика.
Если станция не готова, заявка отклоняется и не выполняется позднее.
Команда относится только к выбранной уставке. Веб показывает результат после
ответа ESP32. При потере ответа состояние не подтверждено.

Обновите и сайт, и десктоп. Форма появится под показаниями после очередной
публикации в GIT WEB. Команда на уставку действует две минуты. Десктоп проверяет
формат команды и идентификатор текущего запуска и сохраняет факт обработки до
отправки на ESP32. После перезапуска команды прошлого сеанса не выполняются.

## Ручная подача через буфер GIT WEB

В блоке титростанции выберите «Ручная подача щёлочи» или «Ручная подача кислоты»,
длительность 1–5 секунд и нажмите «Отправить команду». Команды передаются
в приватном репозитории по пути `data/control/titration-buffer.json`.
Поля `parameter` и `value` передают тег и значение. Для пуска тег
`base_pulse_s` или `acid_pulse_s` принимает длительность, а
`pump_stop` принимает логическое `true`. Команды насосов
действуют 15 секунд. Десктоп запоминает идентификатор через отметку
времени обработки и повторно команду не выполняет.

Запуск требует ручного режима, свежего heartbeat ESP32, остановленных
насосов и действующей взаимной блокировки. Десктоп перед пуском задаёт
аппаратный предел и останавливает подачу своим таймером. После подтверждения
останова возвращаются обычные уставки. При перезапуске после прерванной
подачи десктоп сначала добивается подтверждённого останова. Если подтверждение не пришло,
десктоп продолжает попытки останова. «Стоп WEB-подачи» может заменить
ожидающую заявку в буфере. Git доставляет команды с задержкой, поэтому
штатный аварийный стоп остаётся на панели станции.

На обеих сторонах нужна сборка с новым путём буфера. Режимы и уставки
используют этот же файл. Мониторинг GIT WEB сохраняет существующий latest.json.

## Публикация за внешней защитой

Форма управления открывается по адресу сайта после получения статуса от ПК
станции. Публичный доступ к самому серверу, в том числе к
`POST /api/titration/request`, ограничивает ваша внешняя защита. Внутри
веб-приложения отдельного входа нет.

Старые переменные `AE_AUTOLABS_REMOTE_STATION`, `AE_AUTOLABS_REMOTE_SIGNING_KEY`,
`AE_AUTOLABS_REMOTE_GITHUB_TOKEN` и `AE_AUTOLABS_REMOTE_OPERATOR_KEY` можно удалить.
