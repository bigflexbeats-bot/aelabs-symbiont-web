# AELABS WEB — панель статистики посетителей

- В футер добавлена компактная кнопка «Статистика».
- Панель администратора защищена паролем, серверной Flask-сессией с HttpOnly/SameSite cookie и ограничением неверных попыток входа.
- Считаются активные браузеры (heartbeat за последние 90 секунд), посещения за день, всего сессий, уникальные браузеры, график за 7 дней и активные URL-пути.
- Клиент отправляет только случайные UUID посетителя/вкладки и pathname. IP-адреса, user-agent, имена и параметры URL в аналитическую базу не сохраняются.
- Пароль настраивается через `ANALYTICS_ADMIN_PASSWORD` и не хранится в исходном коде. Ключ подписи сессии задаётся через `FLASK_SECRET_KEY`.
- Поддерживается PostgreSQL через `DATABASE_URL`; без него используется SQLite, которая не гарантирует сохранение истории на Render после перезапуска/деплоя.
- Мониторинг, тренды, история CSV/GitHub и переключение тем не изменялись.

Перед входом в панель задайте `ANALYTICS_ADMIN_PASSWORD` в Render Environment; `FLASK_SECRET_KEY` должен быть отдельным длинным случайным секретом. Подробности — в `VISITOR_ANALYTICS_SETUP_RU.md`.
