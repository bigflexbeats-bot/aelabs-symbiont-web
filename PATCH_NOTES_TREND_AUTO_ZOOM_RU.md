# AELABS WEB — авто-масштаб тренда

- Вертикальная шкала автоматически подстраивается под диапазон видимых параметров.
- Верхняя и нижняя границы имеют небольшой запас, чтобы линии не прилипали к краям.
- При выбросе/росте значения шкала расширяется; при возвращении значений в обычный диапазон шкала приближается снова.
- Сглаженные кривые, цветное свечение, обновление раз в 5 секунд и локальная история сохранены.
- Измерения не изменяются и не нормализуются; меняется только масштаб отображения.

Замените файлы веб-проекта содержимым этой папки и выполните повторное развёртывание.
