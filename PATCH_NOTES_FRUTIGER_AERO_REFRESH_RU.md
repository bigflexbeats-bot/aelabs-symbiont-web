# Frutiger Aero — обновление по референсам

- Полностью переработано оформление темы Frutiger Aero: яркое голубое небо, стеклянные сферы, тропические рыбки, водяные блики и зелёный горизонт.
- Добавлен оптимизированный декоративный фон `static/frutiger-aero-wallpaper.webp`.
- Усилены жидкое стекло, выпуклые градиентные кнопки, глянцевые иконки и панели в духе Windows Vista.
- Изменения касаются только визуального слоя темы `aero`. Темы «Русская» и «Классика», переключатель тем, API, логи и тренды не изменены.
