# Frutiger Aero — оформление по референсам

- Голубое небо, стеклянные сферы, тропические рыбки, водяные блики и зелёный горизонт.
- Жидкое стекло, выпуклые градиентные кнопки, глянцевые иконки и панели в духе Windows Vista.
- Тема доступна как необязательный вариант; по умолчанию включена классическая тёмная тема.
- Оформление не меняет мониторинг, CSV-историю, серверный API или логику трендов.
