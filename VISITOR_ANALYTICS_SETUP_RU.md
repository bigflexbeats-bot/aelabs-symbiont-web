# Панель статистики посетителей AELABS WEB

## Что считает панель
- «Сейчас на сайте» — уникальные браузеры, отправлявшие сигнал в последние 90 секунд.
- «Посещений сегодня» — открытые сессии браузерных вкладок, начатые сегодня по часовому поясу `ANALYTICS_TIMEZONE` (по умолчанию `Europe/Moscow`).
- «Всего посещений» — число зарегистрированных сессий с момента накопления истории.
- «Уникальные браузеры» — приблизительная оценка по случайному идентификатору в localStorage; это не гарантированное число людей.
- График за 7 дней и активные пути сайта.

Скрипт не отправляет и не сохраняет IP-адрес, user-agent, имена или query-параметры URL. Идентификаторы случайные, создаются браузером; heartbeat работает каждые 25 секунд. Посетитель считается активным 90 секунд после последнего сигнала. Панель администратора защищена серверной сессией, HTTPS-cookie и ограничением попыток входа (5 неверных попыток за 15 минут на клиентский IP).

## Настройка Render

1. Откройте Render → сервис `aelabs-symbiont-web` → **Environment**.
2. Добавьте `ANALYTICS_ADMIN_PASSWORD` и задайте выбранный пароль в Render Environment. Сам пароль намеренно не хранится в исходном коде и не попадёт в GitHub.
3. Добавьте `FLASK_SECRET_KEY` со случайным секретом длиной не менее 32 байт. Не используйте пароль панели как ключ сессии. Если сервис создаётся/обновляется через Render Blueprint, `render.yaml` объявляет этот ключ с `generateValue: true`.
4. Сохраните переменные и выполните redeploy. После этого внизу сайта появится кнопка **«Статистика»**; введите пароль `15426`.

## Сохранение истории между деплоями

Если `DATABASE_URL` не задан, статистика пишется в SQLite-файл внутри приложения. Это подходит для первого запуска, но файловая система обычного Render Web Service может очищаться при redeploy/restart, поэтому накопленная статистика может сброситься.

Для постоянной истории создайте PostgreSQL-базу, скопируйте её Internal Database URL (или подходящий URL подключения) в переменную `DATABASE_URL` веб-сервиса и выполните redeploy. Таблицы создаются автоматически при первом запросе. Пакет `psycopg` включён в `requirements.txt`.
