# Редизайн интерфейса

- Новый интерфейс в стиле Apple: стекло, плавные анимации, крупная типографика.
- Загрузочный экран с логотипом; страница открывается после первого ответа сервера.
- Тёмная и светлая тема (переключатель вверху справа, выбор запоминается).
- Для каждого параметра своя живая иллюстрация: pH, DO, температура, мешалка, OD, молекулы O2/CH4/CO2, поток воздуха/O2, ёмкости на весах.
- Убраны поясняющие подписи и коды датчиков; остались название, значение и единица.
- Логика данных, тревог, тренда и истории не менялась. API и переменные Render прежние.
- Логотип уменьшен с 1,6 МБ до ~340 КБ, добавлен кэш статических файлов.
